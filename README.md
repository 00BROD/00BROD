### Selected case studies

**[RFM Reactivation Portfolio](https://github.com/00BROD/rfm-reactivation-portfolio)** — flagship end-to-end case study on 541K real retail transaction rows: SQLite warehouse, deterministic RFM segmentation, cohort/Pareto analysis, an **816-customer ranked win-back list**, and an [interactive dashboard](https://retail-reactivation.vercel.app). The £37K figure is explicitly an adjustable scenario—not a forecast.

**[Ecommerce Revenue Analysis](https://github.com/00BROD/ecommerce-revenue-analysis)** — SQL-first synthetic case study using window functions, CTEs, cohort retention, RFM, and corrected Pareto analysis. Discount-acquired customers generate ~45% less 90-day revenue; CAC and margin are treated as missing inputs, not invented findings.

**[Checkout A/B Test](https://github.com/00BROD/ab-test-checkout-analysis)** — seeded synthetic experiment ending in a ship decision: z-test, Welch t-test, 95% CIs, conversion power, and RPV sensitivity. Conversion rises +1.3pp, but a positive revenue-per-visitor lift is not established—so the recommendation is to iterate and re-test.
